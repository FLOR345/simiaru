# Componentes de React Bits

BlurText, ClickSpark, Counter, CountUp, GlareHover, GradientText, Magnet, RotatingText, ShinyText, SplitText, AnimatedContent, SpotlightCard, StarBorder y TiltedCard vienen de [React Bits](https://reactbits.dev) (variante JS + Tailwind), copiados tal cual al proyecto.
Su licencia (MIT + Commons Clause) está en `LICENSE-react-bits.md`: permite usarlos dentro de SimiAru, pero no vender ni redistribuir los componentes por sí solos.
